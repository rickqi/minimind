# 第 14 章导读:智能体 RL —— 多轮工具使用作为轨迹

> 完整交互版见 [`ch14.ipynb`](./ch14.ipynb)。

## 章节摘要

从单轮 RL 进入多轮 Agentic RL:模型生成 → 调用工具 → 观察结果 → 再生成,整条轨迹作为一个 RL episode。延迟奖励在轨迹结束后计算,通过 gt 命中率提供弱监督。

## 学习目标

- 理解多轮 rollout 的轨迹概念
- 掌握 mock 工具的设计理由(确定性/可复现)
- 理解延迟奖励与 credit assignment
- 理解 response_mask 只覆盖 assistant 生成

## 术语表

| 术语 | 英文 | 解释 |
|---|---|---|
| 轨迹 | Trajectory | 完整的多轮交互序列 |
| 回合 | Turn | 一次生成→工具→观察的循环 |
| 延迟奖励 | Delayed Reward | 轨迹结束后才计算的奖励 |
| 弱监督 | Weak Supervision | 只标注期望结果,不标注中间步骤 |
| 信用分配 | Credit Assignment | 将最终奖励分配到各 token |
