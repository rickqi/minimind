# 第 4 章导读:注意力原子 —— RMSNorm + RoPE + 单头注意力

> 这是 MiniMind 教程的第 4 章。完整的交互版见 [`ch04.ipynb`](./ch04.ipynb)。

## 章节摘要

本章是全教程的**核心章节**。我们从最朴素的 naive self-attention(Q=K=V=x,3 行代码)出发,一步步加入可训练权重(Wq/Wk/Wv/Wo)、causal mask、multi-head split、RoPE 旋转位置编码、GQA 分组共享、QK-Norm 稳定化、KV cache 加速,最终拼出 minimind 源码里那 44 行紧凑的 `Attention` 类(`model_minimind.py:91-134`)。

本章的写作风格是 **naive → compact**:先用笨办法让你彻底理解每个概念「在算什么」,再展示 minimind 如何用一行代码或一个 trick 把它压扁。**每一个 shape 变化都有注释** —— 形状是理解注意力的钥匙。

## 学习目标

读完本章后,你应该能:

- 从零写出 naive self-attention:`Q@K^T/√d → softmax → 加权 V`
- 解释 RMSNorm 为什么比 LayerNorm 少算一次(不减均值)
- 画出 multi-head 的 shape 流程:$(b,T,d) → (b,T,n_h,d_h) → (b,n_h,T,d_h)$
- 手推 RoPE 的 `rotate_half` 和 `cos/sin` 预计算逻辑
- 说出 GQA(`n_kv=4` vs `n_q=8`)省了多少 KV cache 显存
- 解释 QK-Norm 防止 scores 爆炸、softmax 饱和的数学原因
- 理解 KV cache 把生成复杂度从 $O(T^2)$ 降到 $O(T)$ 的代价(显存)
- 逐行读懂 `model_minimind.py:91-134` 的 compact Attention

## 术语表

| 术语 | 英文 | 解释 |
|---|---|---|
| 自注意力 | Self-Attention | 序列内部每个位置对其他位置做加权平均 |
| 缩放点积注意力 | Scaled Dot-Product Attention | $\text{softmax}(QK^T/\sqrt{d_k})V$ |
| 因果掩码 | Causal Mask | 上三角 $-\infty$ 遮蔽未来位置 |
| 多头注意力 | Multi-Head Attention (MHA) | 把 d 维拆成多个头并行算 |
| 分组查询注意力 | GQA | Q 头多于 KV 头,共享 KV |
| 旋转位置编码 | RoPE | 用旋转矩阵编码相对位置 |
| QK 归一化 | QK-Norm | 对 Q/K 的 head_dim 做 RMSNorm |
| KV 缓存 | KV Cache | 缓存历史 K/V 避免重复计算 |
| 绑定头维度 | head_dim | 每个注意力头的维度,minimind = 96 |

## 核心认知

> 注意力不是一个公式,而是一层套一层的工程优化。每一个 trick(RoPE/GQA/QK-Norm/KV cache)都解决了朴素版本的一个具体问题。读源码时,把它们当成「打在朴素公式上的补丁」来理解,就不会觉得复杂。
