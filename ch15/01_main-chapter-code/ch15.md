# 第 15 章导读:进阶 —— 知识蒸馏与 MoE

> 完整交互版见 [`ch15.ipynb`](./ch15.ipynb)。

## 章节摘要

全书最后一章,学两个进阶主题:知识蒸馏(用 teacher 软标签训 student,暴露暗知识)和混合专家(多专家 FFN + 门控路由 + aux_loss 负载均衡)。

## 学习目标

- 理解蒸馏 loss 的温度 T 与暗知识概念
- 掌握 `α·CE + (1-α)·T²·KL` 组合 loss
- 理解 MoE 的 top-1 路由机制
- 理解 aux_loss 如何防止路由崩塌

## 术语表

| 术语 | 英文 | 解释 |
|---|---|---|
| 知识蒸馏 | Knowledge Distillation | 用大模型教小模型 |
| 温度 | Temperature | 软化 softmax 分布的参数 |
| 暗知识 | Dark Knowledge | 非最优 token 的相对打分信息 |
| 混合专家 | Mixture of Experts (MoE) | 多个子网络按需激活 |
| 路由器 | Gate / Router | 决定 token 发给哪个专家 |
| 路由崩塌 | Routing Collapse | 所有 token 只走一个专家 |
| 辅助损失 | Auxiliary Loss | 额外 loss 项用于负载均衡 |
