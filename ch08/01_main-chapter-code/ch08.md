# 第 8 章导读:预训练 —— 下一 token 预测循环

> 完整交互版见 [`ch08.ipynb`](./ch08.ipynb)。

## 章节摘要

预训练是所有后续阶段的基础。本章拆解 minimind 的训练循环骨架 —— 这个骨架被全部 8 个训练脚本共用,差异仅在数据集类和 loss 函数。覆盖余弦 LR、AdamW、AMP 混合精度、DDP 分布式、断点续训。

## 学习目标

- 理解「下一 token 预测」的自监督学习原理
- 掌握 8 个训练脚本共用的骨架结构
- 理解余弦 LR 调度与 warmup
- 理解 AMP/DDP/checkpoint 的工程实现

## 术语表

| 术语 | 英文 | 解释 |
|---|---|---|
| 自监督学习 | Self-supervised Learning | 文本本身作为标签,无需人工标注 |
| 余弦调度 | Cosine Schedule | 学习率按余弦曲线从峰值衰减到底部 |
| 混合精度 | Automatic Mixed Precision (AMP) | 前向用半精度加速,反向用全精度保稳定 |
| 分布式数据并行 | Distributed Data Parallel (DDP) | 多 GPU 各持完整模型,数据分片,梯度同步 |
| 梯度累积 | Gradient Accumulation | 多个小 batch 的梯度累加后更新,等效大 batch |
| 断点续训 | Checkpoint Resume | 保存训练状态,中断后从断点恢复 |
