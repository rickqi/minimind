# 第 1 章导读:大图景 —— LLM 端到端是什么

> 这是 MiniMind 教程的第 1 章。完整的交互版见 [`ch01.ipynb`](./ch01.ipynb)。

## 章节摘要

本章不写任何模型代码,而是**先把 minimind 跑起来**,亲眼看到一个 64M 参数的 LLM 生成文字,然后把整个推理过程拆解成你将在后续 14 章逐层学习的零件。这是「先看森林,再看树」 —— 在深入 RMSNorm 或 RoPE 之前,先理解它们在一个完整推理中扮演什么角色。

## 学习目标

读完本章后,你应该能:

- 说出一个 LLM 的 **6 个生命周期阶段**(分词 → 模型 → 预训练 → SFT → 对齐 → 推理)
- 亲手**加载 minimind 并运行推理**(`eval_llm.py` 或 Python 代码)
- 拆解一次推理的 **4 个步骤**:tokenizer → model forward → sampling → chat_template
- 解释 temperature / top_p / repetition_penalty 各自的作用
- 看懂本教程 **15 章的路线图**和章节间依赖关系

## 术语表

| 术语 | 英文 | 解释 |
|---|---|---|
| 分词器 | Tokenizer | 把文本切成子词(token)并映射成整数 id 的工具 |
| 词表 | Vocabulary | 所有合法 token id 的集合,minimind = 6400 |
| 对话模板 | Chat Template | 把多轮对话结构化成模型能理解的文本格式(ChatML 风格) |
| logits | Logits | 模型输出层对每个词的原始(未归一化)分数 |
| 采样 | Sampling | 从 logits 分布中选一个 token 作为下一个输出 |
| 温度 | Temperature | 控制采样随机性的标量,除以 logits 后再做 softmax |
| 核采样 | Top-p / Nucleus | 只在累积概率达到 p 的词集合中采样 |
| KV 缓存 | KV Cache | 缓存已计算 token 的 Key/Value,避免重复计算 |
| 绑定权重 | Tied Embeddings | 输入 embedding 和输出 lm_head 共享同一套权重 |

## 核心认知

> LLM 不是魔法。它是一个「文本进、文本出」的函数,内部是大量矩阵乘法和 softmax。后面 14 章会把每一层都拆开给你看。
