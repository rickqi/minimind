# 第 10 章导读:LoRA —— 从零实现参数高效微调

> 这是 MiniMind 教程的第 10 章。完整的交互版见 [`ch10.ipynb`](./ch10.ipynb)。

## 章节摘要

第 9 章学了全参 SFT —— 更新模型的每一个参数。本章介绍 LoRA(Low-Rank Adaptation):**冻结原始权重,只训练一个极小的低秩「补丁」**。

本章采用 **naive → compact** 教学路径:先从零手写一个 naive LoRA layer(理解原理),再展示 minimind 的 monkey-patch 实现(理解工程),最后走完训练 → 保存 → 合并的完整流程。

核心公式:$W' = W + \Delta W = W + B \cdot A$,其中 $A \in \mathbb{R}^{r \times d}$, $B \in \mathbb{R}^{d \times r}$, $r \ll d$。

## 学习目标

读完本章后,你应该能:

- 解释 LoRA 的数学原理:为什么 $2rd \ll d^2$,以及「低秩假设」为什么成立
- 手写一个 naive LoRA layer:`x → W(x) + B(A(x))`
- 解释**零初始化技巧**:为什么 $B = \mathbf{0}$(而不是高斯初始化)
- 读懂 minimind 的 `apply_lora`:monkey-patch forward 的原理和闭包陷阱
- 说出 `in_features == out_features` 过滤的设计后果:挂 q_proj + o_proj,跳过 k/v_proj(GQA)
- 解释 LoRA 训练与全参 SFT 的差异:冻结、lr=1e-4(10× SFT)、torch.compile 不兼容
- 演示 save_lora(~0.8 MB) → load_lora → merge_lora 的完整流程

## 术语表

| 术语 | 英文 | 解释 |
|---|---|---|
| 低秩适配 | LoRA (Low-Rank Adaptation) | 冻结原始权重,用两个小矩阵 A、B 近似权重变化 $\Delta W$ |
| 秩 | Rank | 低秩矩阵的有效维度,minimind 用 r=16 |
| 零初始化 | Zero Initialization | B 矩阵初始化为零,保证训练起点等价于原始模型 |
| 猴子补丁 | Monkey-patch | 运行时替换模块的 forward 方法,不修改类定义 |
| 方形过滤 | Square Filter | `in_features == out_features`,只给方形 Linear 挂 LoRA |
| 分组查询注意力 | GQA (Grouped Query Attention) | k/v head 数 < q head 数,使 k/v_proj 非方形 |
| 合并 | Merge | 把 $BA$ 折叠进原始权重 $W$,推理时无需 LoRA |
| 参数高效微调 | PEFT (Parameter-Efficient Fine-Tuning) | 只训练极小部分参数的微调方法总称 |
| 冻结 | Freeze | 设 `requires_grad=False`,参数不参与梯度更新 |
| 优化器状态 | Optimizer State | AdamW 存 momentum + variance,每份和可训练参数等大 |

## 被挂 LoRA 的模块

minimind 的 `in_features == out_features` 过滤:

| 模块 | 维度 | 方形 | 挂 LoRA |
|---|---|---|---|
| `q_proj` | 768→768 | ✓ | ✓ |
| `k_proj` | 768→384 | ✗ | ✗(GQA: num_kv_heads=4) |
| `v_proj` | 768→384 | ✗ | ✗(GQA) |
| `o_proj` | 768→768 | ✓ | ✓ |
| FFN (gate/up/down) | 非方形 | ✗ | ✗ |
| `lm_head` | 768→6400 | ✗ | ✗ |

共 16 个模块(2 × 8 层),每模块 24,576 参数(A+B),总计 393,216。

## 核心认知

> LoRA 不是「廉价版全参微调」,而是一种**不同的微调范式**。它的核心洞察:微调时的权重变化是低秩的。用 $B \cdot A$ 近似 $\Delta W$,参数减少 24×,零初始化保证平滑出发,monkey-patch 实现最小侵入。
