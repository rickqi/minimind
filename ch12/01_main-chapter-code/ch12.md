# 第 12 章导读:对齐 I —— DPO:从偏好学习

> 这是 MiniMind 教程的第 12 章。完整的交互版见 [`ch12.ipynb`](./ch12.ipynb)。

## 章节摘要

SFT 让模型学会「模仿训练数据」,但它学的是统计分布,不是人类偏好。模型可能生成语法正确但有害、啰嗦、答非所问的内容。

经典的对齐方案 RLHF 需要「训练 reward model → PPO 优化」,流程复杂且训练不稳定。**DPO(Direct Preference Optimization)** 的核心洞察:RLHF 的最优策略有闭式解,可以把 reward model 直接消去,变成一个纯监督的损失函数。

核心公式:

$$\mathcal{L}_{\text{DPO}} = -\log \sigma\!\left(\beta \left[(\log \pi(y_w) - \log \pi(y_l)) - (\log \pi_{\text{ref}}(y_w) - \log \pi_{\text{ref}}(y_l))\right]\right)$$

本章采用 **naive → compact** 教学路径:先从数学推导理解 DPO 的起源,再逐行拆解 `train_dpo.py` 的损失函数、参考模型、数据格式和训练配置。

## 学习目标

读完本章后,你应该能:

- 解释 SFT 的局限性,以及为什么 RLHF 复杂而 DPO 简洁
- 推导 DPO loss:从 Bradley-Terry 模型 → KL 约束的闭式解 → 消去 reward model
- 手写 naive DPO loss 并理解 minimind 的 compact 实现(batch 切分技巧)
- 解释参考模型的角色:冻结的 SFT 副本,防止策略偏离导致 mode collapse
- 读懂 DPODataset:`chosen` / `rejected` 格式 + `generate_loss_mask` 标记 assistant span
- 实现 `logits_to_log_probs`:log_softmax → gather → sum over tokens
- 说出 DPO 训练配置的关键差异:lr=4e-8(比 SFT 低 250 倍)、epochs=1、beta=0.15

## 术语表

| 术语 | 英文 | 解释 |
|---|---|---|
| 直接偏好优化 | DPO (Direct Preference Optimization) | 消去 reward model,直接从偏好对优化策略 |
| 偏好对 | Preference Pair | chosen(好) + rejected(差),共享 prompt |
| 参考模型 | Reference Model (ref) | 冻结的 SFT 副本,作为 KL 锚点 |
| 闭式解 | Closed-form Solution | RLHF 最优策略的解析表达式,允许消去 reward |
| 隐式奖励 | Implicit Reward | $\hat{r} = \beta \log(\pi / \pi_{\text{ref}})$,策略自身充当 reward model |
| Bradley-Terry 模型 | Bradley-Terry Model | 用 reward 差表达偏好的概率模型 |
| 灾难性遗忘 | Catastrophic Forgetting | 微调后丢失原有能力,lr 过高时发生 |
| 模式坍塌 | Mode Collapse | 策略把概率推到极端,生成质量崩塌 |
| KL 散度约束 | KL Divergence Constraint | 限制策略偏离 ref 的程度,由 β 控制 |

## 训练配置对比:SFT vs DPO

| 配置 | SFT | DPO | 倍数 |
|---|---|---|---|
| `learning_rate` | 1e-5 | 4e-8 | 1/250 |
| `epochs` | 3 | 1 | 1/3 |
| `batch_size` | 32 | 4 | 1/8 |
| `beta` | — | 0.15 | DPO 专属 |
| ref model | 无 | 冻结副本 | 显存 ×2 |
| 数据格式 | 单条对话 | chosen + rejected 偏好对 | — |

## 核心认知

> DPO 的优雅在于:它把 RLHF 中「训练 reward model → PPO 优化策略」的复杂 pipeline,压缩成了一个可微分的分类损失。模型直接从偏好对中学习「选对边」,梯度清晰,训练稳定。代价是:需要 2 倍显存(冻结的 ref model),且 lr 必须极低(4e-8)防止灾难性遗忘。
